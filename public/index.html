Node.js Fundamentals HTTP Server

Built with the core http, fs, events, and stream modules only - no Express.

Endpoints

  • GET /api/notes - list all notes
  • POST /api/notes - create a note (JSON body: { "title": "", "body": "" })
  • GET /api/notes/:id - get one note
  • DELETE /api/notes/:id - delete a note
  • GET /api/event-loop-demo - triggers a callback ordering demo (watch the server console)
  • GET /api/download-log - streams the access log file as a download
